# Complete Linux x86_64 System Call Reference Handbook

Extracted directly from the Linux Kernel uapi header (`asm/unistd_64.h`).

## Calling Convention (System V AMD64 Kernel ABI)
- **Instruction**: `syscall` (clobbers `rcx` and `r11`)
- **Syscall Number Register**: `rax`
- **Arguments 1..6**: `rdi`, `rsi`, `rdx`, `r10`, `r8`, `r9`
- **Return Value**: `rax` (values in `-4095 .. -1` indicate `-errno`)
